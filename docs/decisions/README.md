# Design decisions

Record significant engineering and AI choices here. Do not require a separate record for trivial implementation details.

## Template
- **Decision and status:** proposed / accepted / superseded
- **User problem and success criterion**
- **Alternatives considered**, including a conventional baseline
- **Evidence and assumptions:** quality, cost, latency, privacy, operational burden
- **Decision and rationale**
- **Failure handling and fallback**
- **How to verify and revisit**

Initial candidates: DOCX extraction approach, clause matching strategy, precedent retrieval baseline vs semantic search, limited real AI semantic interpretation, persistence approach, and UI framework. Avoid preselecting AI before evidence.
